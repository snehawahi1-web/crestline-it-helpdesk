# Crestline Technologies — IT Help Desk

A ServiceNow IT Help Desk and Incident Management project built on a personal developer instance (PDI).

## Project Overview

Crestline Technologies is a fictional technology company used to simulate a real-world IT service management environment.

The goal of this project is to design and configure an internal IT Help Desk solution that allows employees to report IT issues and enables support teams to manage, prioritize, assign, and resolve incidents.

## Objectives

- Configure an IT incident management solution
- Implement users, groups, and roles
- Configure role-based access and security
- Automate incident management processes
- Implement notifications and workflows
- Use JavaScript for custom functionality
- Document testing and results

## Platform & Technologies

- ServiceNow
- ServiceNow Personal Developer Instance (PDI)
- IT Service Management (ITSM)
- Flow Designer
- JavaScript
- GlideRecord
- ACLs
